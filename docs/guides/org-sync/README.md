# 组织同步验收与操作指南

本指南用于验收“组织同步（应用 Secret 模式）”功能的最小闭环与关键场景。

## 适用范围
- 企业微信（WeCom）应用 Secret 同步（user/list + department/list）
- 组织成员映射建议与人工确认
- 线索分配候选过滤（仅已绑定成员）

## 前置条件
- 已配置企业微信渠道账号（corp_id / agent_id / 应用 Secret）
- 应用已配置到「人事助手」以获得组织架构权限
- 系统可访问企业微信接口
- 组织同步页面可访问：`/scrm/org_sync`

## 最小闭环验收（必做）

### 1) 触发组织同步（应用 Secret）
1. 进入 `/scrm/org_sync`
2. 选择渠道、应用类型、账号
3. 点击“同步组织与成员”
4. 观察“同步日志”出现记录，并提示为应用 Secret 模式

### 2) 来源部门与成员展示
1. 左侧部门树可点击切换
2. 右侧成员列表显示姓名/手机号/邮箱
3. `授权状态` 正常显示为“已授权/仅ID”

### 3) 映射建议规则
1. 点击“刷新映射数据”
2. 确认“匹配建议”只包含已授权成员
3. `matched_by` 为 phone/email

### 4) 线索分配候选过滤
1. 进入线索详情 `/scrm/lead_capture/:lead_id`
2. 打开负责人选择
3. 仅显示已绑定成员（已授权 + 已确认映射）

## 建议扩展验收（可选）
- 多账号切换后列表按账号分区展示
- 设置默认组织来源账号后自动选中
- 成员映射确认后，主组织视图聚合展示

## 常见问题排查
- **只显示 ID、无姓名/手机号/邮箱**：应用未配置到「人事助手」，或无组织架构权限
- **部门树为空**：department/list 未返回数据（检查应用权限）
- **成员列表为空**：user/list 权限不足或未完成同步
- **映射建议为空**：成员未授权或无 phone/email
- **线索分配无法选择成员**：未完成映射确认或授权

## 数据库变更说明
- 新增表：`org_sync_source_member_units`（成员-部门关系，用于左侧部门树过滤）
- 同步动作会更新：`org_sync_source_units`、`org_sync_source_members`、`org_sync_source_member_units`

## 迁移提示
- 新增表需要执行迁移（如：`go run ./cmd/database/main.go migrate` 或使用项目既有迁移命令）

## 相关入口
- 组织同步：`/scrm/org_sync`
- 线索详情：`/scrm/lead_capture/:lead_id`
