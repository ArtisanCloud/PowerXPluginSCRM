# 企业微信 OpenWork 代开发接入指南

本文档用于指导 `root` 管理员完成企业微信 OpenWork（第三方代开发）从 0 到可扫码授权的完整配置。


## 1. 目标与流程

目标：
- 在插件中完成一次平台级配置（`suite_id/suite_secret` 等）
- 租户侧“企微代开发”页面可直接生成二维码，管理员扫码即可授权

整体流程：
1. 企业微信服务商后台创建第三方应用，获取 `suite_id/suite_secret`
2. 在企业微信后台配置事件回调（指令回调 URL + Token + AESKey）
3. 在本系统 `插件设置 -> 渠道平台 -> 企业微信(OpenWork)` 填写并启用
4. 租户在“账号接入 -> 企微代开发”点击“生成扫码授权”
5. 企业管理员扫码授权，系统落库绑定并可继续做同步任务

## 2. 前置条件

必须满足：
- 你有企业微信第三方服务商平台权限（可管理第三方应用）
- SCRM 后端可被企业微信回调访问（公网 HTTPS）
- 已执行数据库迁移（含 `social_channel_platform_settings`）

建议：
- 先准备独立子域名作为回调域名（例如 `https://scrm.example.com`）
- 回调域名与证书有效，避免回调握手失败

## 3. 企业微信后台操作（最关键）

### 3.1 创建/进入第三方应用

在企业微信服务商后台：
1. 进入第三方应用管理
2. 新建或打开已有第三方应用（OpenWork）
3. 记录以下字段：
- `SuiteID`（也叫第三方应用 ID）
- `SuiteSecret`（第三方应用密钥）

### 3.2 配置事件回调（指令回调）

在应用配置里找到回调配置，填写：
- 指令回调 URL（Webhook URL）
- `Token`
- `EncodingAESKey`

说明：
- 回调 URL 用于接收企业微信推送事件（包含 `suite_ticket`）
- `suite_ticket` 是换取 `suite_access_token` 的必要参数
- 没有回调入库 `suite_ticket` 时，扫码授权无法成功

### 3.3 配置可信域名/跳转域名（如企业微信后台要求）

按企业微信平台规则配置：
- 网页授权/回跳域名
- 业务域名（如有）

确保与你在系统中配置的 `redirect_uri` 同域或在白名单内。

## 4. 本系统操作（root）

页面路径：`插件设置 -> 渠道平台 -> 企业微信`

填写映射：
- `Suite ID` <- 企业微信后台 `SuiteID`
- `Suite Secret` <- 企业微信后台 `SuiteSecret`
- `Token` <- 回调配置 Token
- `EncodingAESKey` <- 回调配置 AESKey
- `回调地址（redirect_uri）` <- 授权完成后的系统回跳地址（建议填）
- `Suite Ticket` <- 通常留空（由事件回调自动入库）

最后：
1. 打开“启用平台配置”
2. 点击“保存”

## 5. 租户侧授权操作

页面路径：`触点与线索 -> 账号接入 -> 企微代开发`

操作：
1. 点击“生成扫码授权”
2. 企业微信管理员手机扫码
3. 授权完成后，页面状态应从“等待授权”变为“授权成功”
4. 绑定列表中出现企业信息（`corp_id/corp_name/agent_id`）

备注：
- 一般不需要填写“高级设置”
- “高级回退 auth_code”仅用于扫码回调异常场景

## 6. 验收清单

至少满足以下 6 条：
- 渠道平台页面已保存并启用企业微信 OpenWork 配置
- 可成功生成二维码（非空）
- 扫码后状态自动变为“授权成功”
- 绑定列表出现授权企业记录
- `suite_ticket` 已通过回调写入（后端可查）
- 后续同步任务（Tags/Org/External Contacts）可创建

## 7. 常见问题与定位

### 7.1 点击生成二维码报错：缺少 suite_id/suite_secret

原因：
- root 未在“渠道平台”启用配置
- 或保存值为空

处理：
- 重新填写并保存 `Suite ID/Suite Secret`

### 7.2 报错：suite_ticket is required

原因：
- 事件回调未通，`suite_ticket` 没入库

处理：
1. 检查企业微信回调 URL 是否可公网访问
2. 检查 Token/AESKey 是否与企业微信后台一致
3. 查看后端日志是否收到回调事件

### 7.3 扫码后一直 pending

原因：
- 回调事件没到系统
- 或 `redirect_uri`/域名白名单不匹配

处理：
- 校验企业微信后台回调配置与可信域名配置
- 确认 `redirect_uri` 可访问且在允许范围内

### 7.4 需要临时排障，能否手工完成授权

可以：
- 在“高级回退：手动填写 auth_code”里填写 `auth_code` 完成授权
- 但这只是回退方案，不建议常态化使用

## 8. 安全建议

- `suite_secret` 仅限 root 管理员可见/可改
- 定期轮换 `suite_secret` 与 `Token/AESKey`
- 回调域名必须启用 HTTPS
- 生产环境不要在前端日志打印敏感字段

## 9. 当前实现的读取优先级

当前后端读取顺序：
1. `插件设置 -> 渠道平台` 的企业微信 OpenWork 配置（优先）
2. 租户默认企业微信账号的 `suite_*` 凭证（兼容回退）

建议生产只使用第 1 种（平台统一配置）。
