# 渠道附录：WeCom

## 1. 核心检查点

1. 代开发授权已完成且应用已上线。
2. 企业侧可见范围已正确配置。
3. 服务端出口 IP 已加入白名单。

## 2. 典型错误码

1. `60011`: 通讯录权限不足。
2. `48002`: API forbidden（权限或白名单问题）。

## 3. 建议

1. 先跑组织拉取验证权限，再启用线索回写。
2. 回写字段从最小白名单开始，逐步放开。
3. 企业客户标签的关系变更应统一走任务中心回写（`pushback`），避免页面直写造成不可审计。
4. 客户标签关系回写依赖 WeCom `externalcontact/mark_tag`，请确保应用已开通对应接口权限。
