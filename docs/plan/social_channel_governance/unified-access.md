# 渠道接入与配置

## 1. 目标
- 统一接入方式与配置结构，允许能力差异但保持调用与数据口径一致。
- 让上层业务无需关心平台细节，仅通过 `channel/app_type/account` 识别能力。

## 2. 统一接入判定
1. 账号归属一致：Account 绑定租户/部门/负责人。
2. 能力开关一致：统一 Capability 配置模型。
3. 事件入口一致：Webhook/回调统一入口与校验。
4. 数据口径一致：入库字段至少包含 `channel/app_type/account_id/tenant_id`。

## 3. 典型场景
- 新增视频号：绑定账号 → 配置内容/粉丝能力 → 接入回调。
- 新增飞书应用：绑定部门 → 开启消息能力 → 接入事件回调。

## 4. 数据与配置
- ChannelAccount：平台实例与授权信息。
- CapabilityConfig：能力开关与限额。
- WebhookConfig：统一回调入口与签名校验。

## 5. 验收标准
- 能在同一控制台查看所有渠道账号与能力配置。
- 能统一接收事件并正确标注来源。
