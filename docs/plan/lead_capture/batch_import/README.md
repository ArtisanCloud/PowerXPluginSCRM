# 线索获取 - 批量导入

## 目标
支持通过 CSV/Excel 批量导入线索，提升运营录入效率，并保证与现有去重/合并规则一致。

## 功能范围
- 导入模板下载（CSV/Excel）
- 上传导入文件并解析
- 字段映射与校验（姓名/手机号/邮箱至少一项）
- 导入结果反馈（成功/失败条目）

## 接入方式（规划）
- 管理端接口：`POST /api/v1/admin/leads/import`
- 允许上传 CSV 或 Excel，后端统一解析为标准字段

## 关键规则
- 必须走同一套去重/合并逻辑
- 导入过程记录导入批次与失败原因
- 不允许跨租户导入

## UI 草案
- 线索列表页增加“批量导入”入口
- 弹窗：模板下载、文件上传、导入预览、确认导入

## MVP
- CSV 导入 + 基础字段映射
- 导入结果返回成功/失败数量
