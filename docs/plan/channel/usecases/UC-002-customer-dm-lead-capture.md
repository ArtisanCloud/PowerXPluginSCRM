# UC-002 客户私信触发线索入池

## 实现状态

- 状态：部分实现
- 与 004 关系：已实现 WeCom 会话 webhook 入站、幂等、线索会话桥接；“客户首条私信自动建线索”默认不启用
- 当前默认策略：无法关联时进入待绑定池，不自动建线索

## 目标

客户首条私信自动触发线索入池，并与会话建立关联。

## 参与方

- 渠道：企微/飞书/TG/Discord 任一私信入口
- 执行方：SCRM Lead Capture Pipeline

## 前置条件

1. 渠道入口配置为“客户入口”。
2. 已配置默认线索来源映射规则。

## 输入样例

- 客户文本：`想咨询产品价格`

## 处理流程

1. 接收 `channel.message.received`，识别 `actor_type=customer`。
2. 匹配或创建客户会话 `session_id`。
3. 触发 `lead.capture` 规则：抽取来源、关键词、触达时间。
4. 创建线索并写入会话关联。
5. 返回确认消息（人工接入中/已提交外部工单请求）。

## 成功判定

1. 自动创建线索，字段包含渠道来源。
2. 会话与线索有稳定关联键。
3. 可通过 `request_id` 查询完整审计链路。

## 失败分支

1. 渠道未配置来源映射：返回 `SOURCE_MAPPING_MISSING`。
2. 数据落库失败：返回 `LEAD_CAPTURE_FAILED` 并记录告警。

## 004 对齐约束

1. 当前同步/回调链路以 WeCom 为主（`wechat + wecom`）。
2. 自动建线索必须显式规则开启，默认维持“待绑定池”策略。
