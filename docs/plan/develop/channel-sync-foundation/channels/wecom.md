# WeCom 渠道特性（首发）

## 适配范围

- 代开发授权链路（安装、授权、回调、续期）
- 标签双向同步
- 组织架构双向同步
- 外部联系人与线索双向同步

## 特性要点

1. 以代开发模式为主，兼容手工接入模式。
2. 标签、组织、外部联系人能力优先作为首个可运行实现。
3. 组织与线索同步需遵守企业微信权限与可见范围约束。
4. 回写策略默认安全模式，禁止覆盖受保护字段。

## 风险点

- 授权续期与回调稳定性
- 渠道接口限流与短时不可用
- set_scope / 权限边界导致的能力受限

## 与通用层的边界

- 通用层负责任务编排、幂等、重试、冲突队列与审计。
- WeCom 适配器仅实现渠道 API 映射、错误码归一、能力声明。

## 能力矩阵（Phase 1 对齐）

| 能力域 | 状态 | capability_status | 说明 |
|---|---|---|---|
| 授权接入（代开发） | 支持 | supported | 首发主路径 |
| 手工接入兼容 | 支持 | supported | 存量兼容/降级 |
| 标签双向 | 支持 | supported | 全量+增量 |
| 组织双向 | 支持 | supported | 部门/成员 |
| 外部联系人入池 | 支持 | supported | 渠道到本地 |
| 线索回写 | 部分支持 | partial | 受白名单与保护字段约束 |
| set_scope 动态收口 | 不保证 | not_supported | 依赖企业侧权限与可见范围 |
