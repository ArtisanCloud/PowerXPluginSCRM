# Feishu 渠道特性（扩展）

## 适配目标

- 复用通用同步封装与工厂注册能力。
- 在不改动主流程契约的前提下接入 Feishu 授权与同步能力。

## 首批建议范围

1. 账号授权与绑定关系接入。
2. 标签域双向同步。
3. 组织架构同步（先单向验证，再双向）。
4. 线索相关能力按字段映射成熟度逐步开放回写。

## 约束与注意点

- 与 WeCom 在权限模型、事件模型、字段命名存在差异。
- 需要单独定义错误码映射与重试分类。
- 需要渠道能力声明，避免未支持能力被误调用。

## 与通用层协作

- Feishu 适配器实现统一接口：auth/tag/org/external_contact/lead。
- 工厂按 `channel + app_type` 解析到 Feishu 实现。
