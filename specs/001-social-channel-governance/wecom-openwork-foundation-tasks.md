# WeCom 代开发与双向同步前置任务（补充）

## 目标

在继续“渠道活码”功能前，先完成企业微信渠道接入底座升级，覆盖：

1. 企业微信代开发（OpenWork）授权接通主流程。
2. 标签双向同步。
3. 组织架构双向同步。
4. 外部联系人与线索双向同步。

## 关键约束（已确认）

1. 单租户可绑定多个企业微信企业（multi-corp）。
2. 同一租户同一时刻仅允许一个“系统默认企业账号”。
3. 默认企业切换策略：仅对新任务生效（运行中任务不受影响）。
4. 接入策略：双轨并行（代开发主流程 + 手工参数模式兜底）。
5. 应用策略：支持“授权已有应用”与“自动创建/配置辅助”两种模式。

## 术语与边界

1. OpenWork：企业微信服务商代开发链路（suite_ticket / pre_auth_code / auth_code / permanent_code）。
2. OpenPlatform：微信开放平台（公众号/小程序生态），不作为企业微信代开发主链路。
3. 本文仅定义任务与验收，不替代 API 合同与数据模型文档。

## Phase A：代开发接通（P0）

### A1. 回调与授权链路

1. 增加 OpenWork 回调接收与验签解密能力。
2. 支持 `suite_ticket` 持久化与刷新。
3. 支持 `create_auth/change_auth/cancel_auth/reset_permanent_code` 事件落库与状态迁移。
4. 新增授权发起接口：预授权码生成、授权链接/二维码生成。
5. 新增授权完成处理：`auth_code -> permanent_code`、拉取授权企业信息。
6. 回调链路采用“快速 ACK + 异步处理”，主链路不执行长耗时外部调用。
7. 建立跨实例幂等机制（`tenant + suite + auth_code`），避免重复事件导致重复兑换。
8. 增加分布式互斥，保证同一 `auth_code` 在多实例并发下只会被一个 worker 实际兑换。
9. 定义 `40078 invalid auth_code` 收敛策略：已成功则按幂等成功处理；未成功则标记需重授权并记录原因。

### A2. 账号与默认企业规则

1. 建立租户-企业-应用绑定模型。
2. 实现“每租户唯一默认企业账号”约束（服务层 + 存储层）。
3. 实现默认企业切换，仅影响新创建任务。
4. 保留手工参数接入模式作为回退路径。

### A3. UI 与运维可见性

1. 增加“代开发接通向导”页（授权、回调、完成状态）。
2. 增加授权状态面板（已授权/失效/待重连）。
3. 增加重授权入口与失败原因展示。

### A 验收

1. 不手填核心密钥参数即可完成新租户接入。
2. 回调事件完整入库，可追溯状态变化。
3. 默认企业唯一约束生效，切换默认不影响运行中任务。
4. 同一授权事件重复投递不引发重复兑换，最终绑定状态一致。
5. 回调 ACK 延时达标（P95 < 1s），`40078` 有明确处置闭环。

## Phase B：标签双向同步（P0）

1. 补齐本地标签模型（标签组、标签、映射关系、版本）。
2. 企业微信 -> 本地：全量初始化 + 增量事件同步。
3. 本地 -> 企业微信：创建/更新/删除回推。
4. 冲突策略：远端优先 + 本地冲突队列。
5. 建立幂等键、重试与死信处理。

### B 验收

1. 双向标签变更可收敛。
2. 冲突、失败、重试可审计可重放。

## Phase C：组织架构双向同步（P0）

1. 部门/成员映射模型标准化。
2. 全量同步 + 增量事件同步。
3. 支持本地变更回推（增删改、启停、调部门）。
4. 处理离职、禁用、跨部门等边界场景。

### C 验收

1. 部门树、成员状态双向一致。
2. 无重复成员、孤儿部门、失联映射。

## Phase D：外部联系人与线索双向同步（P0）

1. 外部联系人入池（WeCom -> 线索）。
2. 线索关键字段回写（线索 -> WeCom）。
3. 去重策略：`external_userid + 手机 + 企业 + 渠道`。
4. 状态映射与字段回写白名单，避免覆盖人工字段。

### D 验收

1. 双向同步稳定，无明显污染或错配。
2. 去重准确率与回写成功率达标。

## Phase E：稳定性与门禁（P0）

1. 建立任务中心：排队、重试、死信、手工重放。
2. 建立观测面板：成功率、延迟、冲突、失败 TopN。
3. 完成 7 天稳定性验证。

### E 验收（渠道活码重启门禁）

仅当以下全部满足时，恢复渠道活码增强开发：

1. 代开发接入可用且可重连。
2. 标签双向同步稳定。
3. 组织架构双向同步稳定。
4. 外部联系人与线索双向同步稳定。
5. 任务重试、审计、重放能力完备。
